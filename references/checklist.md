# 企业 AI 流程自查清单 · 完整检查项

> 与 GenSight AI Excel 清单逻辑一致。Skill 访谈时按 Phase 1→4 顺序提问。

---

## Phase 1 · 01 企业背景

### 基本信息

- 公司名称、规模（人数）、行业/业务类型
- 联系人/职位、所在城市/主要市场
- 主营业务/核心产品线
- 组织架构简述（主要部门及分工）
- 已在使用的 AI 工具
- 目前谁在推动 AI 落地

### 企业基本情况总结（200–500 字）

描述：做什么、怎么赚钱、团队怎么协作、近 6–12 个月重点。

### 经营问题（尽可能详细）

| 维度 | 引导问题 |
| --- | --- |
| 总述 | 最头疼的 3–5 个经营/管理问题 |
| 战略/方向 | 方向不清？各部门各干各的？目标与动作对不上？ |
| 业务运转/流程 | 线索断？需求不清反复改？跨部门靠人传话？ |
| 团队/管理 | 开完会没人接？责任不清？老员工不在就卡？ |
| 客户/销售/交付 | 资料散在微信？方案版本乱？交付总返工？ |
| 三个月一件事 | 如果只能改一件事，改什么？为什么？ |

**质量要求**：每个问题至少 1 个具体场景（环节 + 人员 + 频率 + 业务后果）。

## Phase 2 · 02 流程自查

### A · 现状判断（是/否）

| # | 描述 |
| --- | --- |
| A1 | 员工各自在用 AI，但部门之间还是对不上 |
| A2 | 工具买了、培训做了，整体交付周期和返工率没有明显变化 |
| A3 | 真正耗时间的是交接、等待、返工、对齐 |
| A4 | 每个部门自己找工具，没有统一方向 |
| A5 | 堆了多种 AI 工具，但没有一条流程真正跑通 |
| A6 | 工具配了，流程没改，责任没定，验收没有 |

→ 初步判断：1=偏点 / 2=偏线 / 3=两者兼有

### B · 买工具前四件事

| # | 内容 |
| --- | --- |
| B1 | 战略方向（6–12 个月）：增收/降本/提效/降流失/复制能力 + 一句话描述 |
| B2 | 业务结构：钱从哪来、活从哪进、活怎么交 + 已知断点 |
| B3 | 选 1 条真实在跑的业务链：谁发起→经过谁→信息放哪→谁审批→谁负责 |
| B4 | 根本问题：获客/转化/交付返工/管理失控/决策慢/跨部门协同 + 原因 |

### G · 暂缓清单（任一项「是」建议先缓）

| # | 描述 |
| --- | --- |
| G1 | 流程本身还没定义清楚，全靠个人习惯 |
| G2 | 责任人不清楚，没人敢拍板、没人验收 |
| G3 | 没有衡量标准，改前改后说不清 |
| G4 | 预期全公司一夜之间自动化 |
| G5 | 涉及报价/合同/隐私，但未设计人工审核 |
| G6 | 老板/负责人未参与，纯 IT 或员工推动 |

→ 结论：1=可以启动试点 / 2=暂缓 / 3=需进一步诊断

### 老板三个必答题

1. 我们到底要先解决哪个业务问题？
2. 哪个场景最值得先试（线头）？
3. 谁对结果负责、怎么验收？

## Phase 3 · 03 部门盘点

每个部门一行：

| 字段 | 说明 |
| --- | --- |
| 部门 | 部门名称 |
| 高频工作 | 摘要 |
| 当前痛点 | 具体描述 |
| 类型 | 重复 / 繁琐 / 有壁垒 |
| 跨部门 | 是 / 否 |
| 负责人 | 姓名或角色 |
| 备注 | 可选 |

**规则**：只讨论工作场景，先不讨论 AI。

## Phase 4 · 04 试点方向

### D · 场景归类

- 重复型：资料整理、录入、纪要等
- 繁琐型：多版本方案、跨部门传话等
- 有壁垒型：策略判断、关键审核等
- 高风险型：报价、合同、客户隐私等

### E · 找线头

对 2–3 个候选业务链评分（每项 0–5）：

- 高频
- 痛苦
- 可衡量
- 风险可控

合计 ≥16 → 优先试点。选定 1 个线头并说明与业务结果的关联。

### F · AI 介入前 7 问

| # | 问题 |
| --- | --- |
| F1 | 业务结果：改完希望看到什么具体变化？ |
| F2 | 频率：多久发生一次？涉及多少人？ |
| F3 | 输入：现在的输入是什么？ |
| F4 | 责任人：谁对最终结果负责？谁验收？ |
| F5 | 审核：哪几步可以交给 AI？哪几步必须人工确认？ |
| F6 | 例外：什么情况 AI 不能处理，必须升级给人？ |
| F7 | 指标：改之前什么样，改之后怎么判断有没有变好？ |
